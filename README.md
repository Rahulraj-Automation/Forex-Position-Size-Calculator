# Forex Position Size Calculator

A Python and Streamlit application that helps traders calculate position size based on account balance, risk percentage, and stop-loss distance.

## Features

- Position size calculation
- Risk percentage calculation
- EURUSD support
- GBPUSD support
- USDJPY support
- XAUUSD support
- NAS100 support
- US30 support
